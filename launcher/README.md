# Лёгкий загрузчик Штампилятора

`Штампилятор-1.2.1-bootstrap.exe` — отдельный маленький загрузчик (около
63 КБ). Он не содержит PySide6/PyMuPDF/Python и при первом запуске скачивает
рабочий архив `runtime-1.2.1.zip` (около 87 МБ).

## Как работает

1. Проверяет, установлена ли версия 1.2.1 в
   `%LOCALAPPDATA%\Shtampilyator\runtime\1.2.1`.
2. Если нет — скачивает runtime-архив по HTTPS.
3. Проверяет SHA-256.
4. Распаковывает и запускает `Штампилятор.exe`.
5. При следующих запусках интернет не нужен.

## Источник архива

По умолчанию используется GitHub Releases:

```text
https://github.com/webbedmouse-eng/Stampilyator/releases/download/v1.2.1/runtime-1.2.1.zip
```

Если архив размещён в другом месте, положите рядом с загрузчиком файл
`runtime.url` с прямой HTTPS-ссылкой или передайте её параметром:

```powershell
.\Штампилятор-1.2.1-bootstrap.exe --url "https://example.com/runtime-1.2.1.zip"
```

Хеш можно переопределить файлом `runtime.sha256` или параметром `--sha256`.

## Портативный режим

По умолчанию runtime распаковывается в `%LOCALAPPDATA%`. Если запись туда
запрещена, загрузчик пробует папку рядом с собой и `Документы\Shtampilyator`.
Для теста или портативного размещения можно указать каталог:

```powershell
.\Штампилятор-1.2.1-bootstrap.exe --data-dir "D:\Shtampilyator"
```

или переменной окружения `SHTAMPILYATOR_DATA_DIR`.

## Сборка

Из корня проекта:

```powershell
.\build.ps1
.\build_launcher.ps1
```

`build_launcher.ps1`:

- копирует `dist\Штампилятор-1.2.1-win64.zip` в `dist\runtime-1.2.1.zip`;
- пересчитывает SHA-256 и обновляет константу в `Launcher.cs`;
- компилирует загрузчик через `csc.exe` из .NET Framework 4.8;
- проверяет, что размер меньше 8 МБ.

## Важно

Загрузчик не заменяет полноценный портативный архив. Если пользователю нужен
офлайн-запуск без первой загрузки, распространяйте
`Штампилятор-1.2.1-win64.zip`.
